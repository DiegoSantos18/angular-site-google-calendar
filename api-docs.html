Como usar esta API

A aplicação Angular chama esta API pelo proxy local durante o desenvolvimento e pelo domínio Vercel em produção. Comece por GET /api/calendar?action=get-calendars; use um ID retornado no cabeçalho x-google-calendar-id para listar, criar ou excluir eventos. O calendário principal nunca é aceito.

As credenciais Google ficam no servidor. Todas as operações são públicas e não exigem login. Qualquer pessoa pode criar ou excluir calendários e eventos acessíveis à API; CORS não bloqueia chamadas HTTP diretas.
